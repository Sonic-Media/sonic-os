BUG FOUND AND FIXED
-------------------
Issue:
  Sales created through the API received staffId from the logged-in user but
  staffName was saved as null in PostgreSQL and the UI.

Root cause:
  completeSale() resolved staffId from the session but only copied staffName
  from the request body, not from the linked Staff record.

Fix:
  lib/server/services/sales-service.ts — when staffId is resolved and
  staffName is missing, load the staff member name before saving.
